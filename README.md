# 🏦 AI-Powered Banking Fraud Detection & NLP Complaint Classification System

## 📌 Project Overview

This project is an AI-powered banking assistant system that combines:

- Fraud transaction detection using Machine Learning
- NLP-based customer complaint classification
- Streamlit web application interface
- Data visualization and analytics

The project simulates real-world banking AI applications such as fraud monitoring and automated complaint analysis.

---

# 🚀 Features

## ✅ Fraud Detection System
- Detects potential fraudulent transactions
- Uses Machine Learning concepts
- Includes confusion matrix visualization
- Includes feature importance analysis

## ✅ NLP Complaint Classification
- Classifies customer complaints into categories:
  - Fraud
  - Loan
  - ATM
  - Card
- Uses Natural Language Processing (NLP)

## ✅ Streamlit Web App
- Interactive banking AI interface
- Real-time prediction display
- User-friendly UI
